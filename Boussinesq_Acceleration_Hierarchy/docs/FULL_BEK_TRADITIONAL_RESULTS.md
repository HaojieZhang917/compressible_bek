# 全 BEK 家族传统 Boussinesq 基本流适用性结果

## 1. 结果性质

本报告给出传统盘系离心 Boussinesq 相似性方程在加热条件
`Tw >= 1` 下，从等温解连续出发的**数学可解范围**。它回答：

- 等温相连基本流在什么壁温首先遇到有限鞍结；
- 什么时候没有有限鞍结，而是因 `Hinf -> 0-` 失去指数衰减热尾；
- `Ro=0` 和 `Ro=1` 为什么必须单独处理；
- 正 Rossby 数分支在已验证温度范围内是否出现折叠。

这些上限不是相对于可压缩方程的 Boussinesq 精度界限。传统近似的物理
准确性仍要求小密度变化；尤其是 `Tw` 接近 2 的结果只能解释为形式可解性。

## 2. 统一参数化

计算采用

```text
B = Lambda_cf(Ro)*(Tw-1),
Lambda_cf = Co^2/(4Ro),
Theta = (T-1)/(Tw-1),
Co = 2-Ro-Ro^2.
```

在数值残差中延拓有限的 `B` 和归一化温度 `Theta`，最后再换算 `Tw`。
这避免了 `Ro -> 0` 时直接计算“巨大系数乘极小温差”的病态运算，同时保留
了传统模型在 Ekman 极限不一致这一物理事实。

生产参数为

```text
N=120, (a,b,c)=(2,0.6,0.5), Pr=0.72, residual tolerance=1e-9.
```

## 3. 机制分区

### 3.1 von Karman 邻域：有限鞍结

在

```text
-1 <= Ro <= approximately -0.9938
```

内，等温相连分支首先遇到有限壁温鞍结。代表值为：

| `Ro` | 第一鞍结 `Hinf` | 上限 `Tw` |
|---:|---:|---:|
| -1.0000 | -0.532764 | 1.048021731 |
| -0.9990 | -0.529153 | 1.049011593 |
| -0.9980 | -0.524320 | 1.050052819 |
| -0.9950 | -0.495575 | 1.053598557 |
| -0.9940 | -0.468344 | 1.055021561 |
| -0.9938 | -0.448737 | 1.055343996 |

固定 `B` Jacobian 的行缩放最小奇异值比在主折叠处降至约
`1e-8--1e-6`。既有第二折叠数据表明两折叠在
`-0.9938 < Ro < -0.9936` 内成对湮灭。精确 cusp 坐标仍需 bordered
fold/cusp 方程；本报告使用的是经过分辨率检查的括区。

### 3.2 负 Ro、离开 von Karman 端点：无限热尾

折叠对湮灭后，等温相连分支不再遇到有限 `Tw` 鞍结，而是趋向

```text
Hinf -> 0-,
ell_T = 1/(Pr*(-Hinf)) -> infinity.
```

最终温度上限及其估计不确定度为：

| `Ro` | 热尾上限 `Tw` | 估计不确定度 |
|---:|---:|---:|
| -0.9936 | 2.000 | 0.010 |
| -0.9900 | 2.000 | 0.003 |
| -0.9500 | 1.9953 | 0.0030 |
| -0.9000 | 1.9791 | 0.0015 |
| -0.8000 | 1.9345 | 0.0040 |
| -0.7000 | 1.8672 | 0.0041 |
| -0.6000 | 1.7856 | 0.0029 |
| -0.5000 | 1.6919 | 0.0014 |
| -0.4000 | 1.5871 | 0.0012 |
| -0.3000 | 1.46945 | 0.00052 |
| -0.2000 | 1.33612 | 0.00010 |
| -0.1000 | 1.182245 | 0.000045 |
| -0.0500 | 1.095297 | 0.000004 |
| -0.0200 | 1.039220 | 0.000001 |
| -0.0100 | 1.019803 | 0.000001 |

`Ro=-0.99,-0.95,-0.9` 的专门 `N=80,120,160` 伪弧长计算显示，低阶
分支在小负 `Hinf` 处出现的折返随分辨率按约 `N^-2` 向零移动，同时
`ell_T` 增长至 `O(10^3)`。改变映射尺度 `a=1.5,2,2.5` 只移动这一
欠分辨折返，不产生收敛的有限鞍结。因此这些端点分类为无限热尾。

靠近 `Ro=0-`，热尾极限满足数值渐近关系

```text
B_limit -> -2,
Tw_limit - 1 approximately -2 Ro.
```

所以传统差分旋转尺度下允许的非等温区间收缩到零。

### 3.3 Ekman 极限 `Ro=0`：系数/尺度非一致

`Lambda_cf=Co^2/(4Ro)` 在 `Ro=0` 发散。固定 `Tw>1` 时，热离心强度
`B` 无界，因此当前传统 BEK 差分旋转尺度没有一致的非等温 Ekman
极限。这里的适用范围只能标为等温点 `Tw=1`；这不是鞍结，也不是普通
热尾终点。若研究热 Ekman 层，必须重新选择热驱动与速度尺度并独立建模。

### 3.4 正 Ro：加热分支未发现有限鞍结

对于采样的

```text
Ro=0.01,0.02,0.05,0.1,...,0.99
```

加热对应 `B>0`，并使 `Hinf` 更负、热尾更短。所有分支均连续计算到
`Tw=2`，未发现折叠。固定 `B` Jacobian 的最小奇异值比相对于等温值
没有下降：`Tw=2` 与 `Tw=1` 的比值约为 `1.00005--1.66`，所以没有
临界软化证据。

结论只能写为“数学分支已验证到 `Tw=2` 且未发现有限上限”，不能把
`Tw=2` 解释为物理 Boussinesq 准确性界限。

### 3.5 Bodewadt 端点 `Ro=1`：温度被动

在 `Ro=1`，`Co=Lambda_cf=0`。当前传统盘系离心闭合中的温度项从
动量方程完全消失，因此速度基本流与 `Tw` 无关，模型本身不给出有限
壁温上限。这反映的是闭合退化，不等于高温 Bodewadt 流在物理上始终
满足 Boussinesq 近似。

## 4. 后续研究的基本流使用规则

1. 后续程序读取
   `work/results/full_bek_traditional_availability/production_v2_N120_a2.0_b0.6_c0.5/final_applicability.csv`
   作为传统模型的机制和壁温上限索引。
2. 使用同目录 `profiles/` 中的生产剖面作为基础数据；不得使用被中断的
   `production_N120...` 或 `smoke_*` 目录作定量结论。
3. 折叠区的等温相连基本流必须满足 `Tw<Tw_fold(Ro)`；临界附近计算要
   同时监测固定温度 Jacobian。
4. 热尾区必须记录 `Hinf` 和 `ell_T`。接近表中上限而没有尾长收敛检查
   的结果不得进入稳定性或模型比较。
5. 正 Ro 只确认到 `Tw=2` 的数学可解性；用于物理结论时仍应限制在小
   密度变化范围，并等待低马赫/可压缩对照。
6. `Ro=0` 不允许直接调用当前非等温传统残差；需要单独的热 Ekman
   变量尺度。
